# Ravi Sai Teja — Portfolio

A responsive, recruiter-focused personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

1. Create a new public repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://saitejaravi2300.github.io/portfolio/`
